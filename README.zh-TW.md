## 這是什麼

基於 MaiScan 二次製作的 **maimai DX 本地離線曲庫工具**，已支援以下功能：

| 功能 | 說明 |
| :-- | :-- |
| **封面識曲** | 在**選歌階段**拍攝曲繪辨識歌曲，查看部分樂曲資料<br>支援**曲繪儲存**、**文字內容複製**，以及快速搜尋更多資訊 |
| **歌曲搜尋** | 支援以**曲名 / 曲師 / 別名 / 定數 / ID** 搜尋歌曲<br>藉助**特殊別名**，還可搜尋**版本號**、**刪除曲**、**宴會場**、主題曲等 |
| **收藏系統** | 將喜歡的樂曲進行收藏，收藏夾支援**層級疊加**<br>可匯入匯出 **`.msrf`** 檔案，設定**唯讀**與**暴力還原**<br>也鼓勵玩家製作**收藏整合包**進行分享 |
| **曲庫方面** | 收錄幾乎所有 maimai 的歌曲<br>包括**精文舞萌獨佔曲**、**刪除曲**、**舊框體宴會場**等<br>合計**超過 1900 首**，透過公開資料手動整理 |
| **外觀設定** | 既有為低效能裝置準備的原生 MaiScan 介面（**Legacy**）<br>也有基於 **Material** 與 **Miuix** 的新 UI，支援**自訂主題**介面 |
