## 功能

**拍照识曲** —— 对着机台屏幕拍一张，直接认出曲目。

**曲库查询** —— 曲名、曲师、定数、物量、别名、ID；四类一起搜。

**收藏夹** —— 真正的文件夹树，`.msrf` 收藏包导入导出，只读保护，批量复制与移动。

**外观** —— Material 3、Miuix、Legacy 三套界面；四种语言；按设备支持的最高刷新率运行。

## 隐私

应用不含 `INTERNET` 权限，在原理上无法把任何数据发送出去。

只申请三项权限：相机，以及外部存储的读取与写入 —— 用于保存照片、导入导出收藏包。
没有账号，没有统计，没有广告。
