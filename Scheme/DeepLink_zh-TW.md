# MaiScan Rev 深層連結（`maiscan://`）規範

**版本**：1.0　**適用**：MaiScan Rev `build.20261126` 及以後　**平台**：Android 6.0 以上（`run` / `play` 需新版介面，見第 11 節）

本文件適用於希望從其他應用程式、NFC 標籤、QR Code 或自動化工具喚起 MaiScan Rev 並執行指定動作的開發者與進階使用者。

## 1. 概述

`maiscan://` 讓外部呼叫 MaiScan Rev 執行以下動作：

- 開啟主介面
- 開啟指定曲目的詳細頁
- 將指定曲目的檔案交給外掛所指定的目標應用程式
- 將指定曲目送入 MaiScan 內建播放器

---

## 2. 連結結構

```
maiscan://info/songID=<曲目 ID 或 random>{參數列表}
```

| 連結 | 行為 |
|---|---|
| `maiscan://` | 開啟主介面（裸 scheme 視為合法連結）|
| `maiscan://info/songID=10721` | 開啟 10721 的曲目詳細頁 |
| `maiscan://info/songID=random` | 隨機選一首，開啟其詳細頁 |
| `maiscan://info/songID=10721{plugin="com.exp.pack",action=run,execution=1}` | 靜默執行：直接將該曲檔案交給外掛指定的目標應用程式 |
| `maiscan://info/songID=10721{action=play}` | 送入內建播放器；未啟用播放器時停留在詳細頁 |

**書寫慣例**

- 參數列表以 `{` `}` 包住，參數之間以 `,` 分隔，形式為 `key=value`。
- 字串值建議使用雙引號；`songID` 的值可加可不加引號。
- `{` `}` `"` 不是標準 URI 字元。若寫入工具做了百分比編碼（`%7B` `%7D` `%22`），MaiScan 會先解碼再解析，兩種寫法都支援。

---

## 3. 參數說明

| 參數 | 取值 | 含義 |
|---|---|---|
| `plugin` | 外掛套件名稱 | 負責執行動作的外掛。整合包可寫**父包**（會自動定位對應子包），也可直接寫**子套件名稱**：此時只作用於該子包，範圍更窄。子包要求父包已啟用且該子包未被停用 |
| `action` | `run` / `play` | 執行動作，見第 4 節 |
| `execution` | `1` / `0` / 省略 | 是否靜默執行，見第 5 節。相容 `true` / `false` |
| `sweep` | `1` / `2` / 省略 | 僅對 `action=run` 生效，見第 7 節 |
| `wlist` | `"1,2,3"` | 僅 `songID=random` 時生效：白名單 |
| `blacklist` | `"1,2,3"` | 僅 `songID=random` 時生效：黑名單 |
| `debug` | `1` / `0` | `1` 時以 Toast 顯示執行步驟；省略或 `0` 時不顯示任何提示 |

未辨識的參數會被忽略，不影響連結有效性。

---

## 4. 動作 `action`

| 值 | 行為 |
|---|---|
| `run` | 模擬詳細頁中的外掛按鈕。FILE 類：將該曲檔案交給外掛指定的目標應用程式；WEB 類：以瀏覽器開啟其指定的網址 |
| `play` | 將音訊送入 MaiScan 內建播放器。解析成功後回到主介面，由懸浮播放器繼續播放；內建播放器未啟用時停留在該曲詳細頁並於頁內播放 |

**`play` 的音訊來源**

1. 優先依曲目 ID 從已啟用的外掛解析：`.aiu`（搭配 `.arup`）、`.adx`、`.mp3`、`.ogg` / `.oga`、`.flac`、`.wav`；
2. 解析不到時，退回外掛按鈕所宣告的可播放檔案。

`play` 不需要 `plugin`；其他格式（如 `.m4a`、`.aac`、`.opus`）是否可播取決於裝置解碼能力，不保證支援。

### WEB 外掛

WEB 類外掛沒有檔案也沒有目標套件，只有網址（`Webrule.json` 的 `url`）。對其使用 `action=run` 會直接用瀏覽器開啟該網址，佔位符 `[id]`、`[title]`、`[artist]` 照常替換。

- 網址 scheme 不限：`https://` 與自訂 scheme（如 `astrodx://…`）都由系統分派。
- 防遞迴：若外掛的目標位址仍是 `maiscan://`，該次呼叫直接判定失敗並停留在詳細頁。
- FILE 類同理：目標套件指向 MaiScan 自身時會被拒絕。
- WEB 外掛不支援 `sweep`，因為它不涉及在目標應用程式內匯入。

---

## 5. 靜默執行 `execution`

| 值 | 行為 |
|---|---|
| `1`（或 `true`）| 嘗試靜默：執行成功時不顯示任何介面 |
| 省略 / `0`（或 `false`）| 先開啟詳細頁，再由應用程式模擬執行對應按鈕 |

---

## 6. 隨機選曲 `songID=random`

將 `songID` 寫為 `random`（大小寫不敏感）即可隨機選擇一首曲目。

**過濾規則（依序套用）**

1. `wlist` 非空時，僅在其中選取；
2. 排除 `blacklist` 中的曲目；
3. 指定了 `plugin` 時，僅保留該外掛涵蓋的曲目：需符合 `[SongList]` / `%file%` 規則；FILE 類還要求確實存在檔案（`pack-all` 視為全部涵蓋）；整合包允許父包或任一已啟用子包命中；若寫的是子套件名稱，則只在該子包範圍內選取。

若候選為空，視為「曲目不存在」，進入主介面且不顯示提示。

```
maiscan://info/songID=random
maiscan://info/songID=random{wlist="10721,10722"}
maiscan://info/songID=random{blacklist="9"}
maiscan://info/songID=random{action=play}
```

## 7. 執行中的目標 `sweep`

目標應用程式（例如 AstroDX）只在冷啟動時讀取匯入內容，執行中收到新的啟動請求會忽略。`sweep` 用於「目標已經在執行」時嘗試匯入。

| 值 | 做法 | 實測結果（僅 AstroDX）|
|---|---|---|
| 省略（=0）| 一般啟動 | 目標在背景：**無法注入**；把目標重新啟動後再試也一樣。目標在前景：啟動會**直接崩潰**，且沒有後續拉起，可能直接看到錯誤彈窗（Unity）|
| `sweep=1` | 與 0 相同，但崩潰後會**再次拉起目標應用程式** | 同樣會出現崩潰彈窗，但大多一閃而過；若彈窗沒有被關閉／取消，匯入會繼續執行 |
| `sweep=2` | 讓目標在自己的任務堆疊中新開一個任務 | 通常不會崩潰；代價是每觸發一次，最近任務就多一條該應用程式 |

⚠️ 以上**僅實測 AstroDX**；其他 App 的行為不確定，其他「Unity 且支援外部匯入」的 App 理論上同理。

使用 `sweep` 時一律走靜默匯入流程，`execution` 不再影響是否靜默。

兩種模式都會在匯入後約 1.8 秒嘗試將目標應用程式拉回前景；失敗時僅記錄日誌，`debug=1` 時以 Toast 提示。

## 8. 失敗落點

| 情況 | 落點 |
|---|---|
| 連結格式錯誤 / 無法解析曲目 ID / ID 不在曲庫 | 主介面（不提示）|
| ID 有效但未指定 `plugin` 與 `action` | 曲目詳細頁 |
| 參數不合法（如 `action` 非 `run` / `play`）| 曲目詳細頁 |
| 外掛未安裝 / 已安裝未啟用 | 曲目詳細頁 |
| 外掛中不存在該曲檔案 | 曲目詳細頁 |
| 目標應用程式未安裝或拒絕該檔案 | 曲目詳細頁 |
| `action=play` 解析不到音訊 | 曲目詳細頁 |

> 外掛必須「已安裝且已啟用」才會執行，與詳細頁按鈕的顯示規則一致。

## 9. NFC 標籤

- 寫入一筆 **URI 記錄**，內容為本文件中的 `maiscan://…` 連結。
- 建議同時寫入一筆 **AAR（Android Application Record）**：`com.MaiScan.Rev`。如此一來，即使裝置上有其他宣告 `maiscan://` 的應用程式，系統也會將意圖直接交給 MaiScan。
- MaiScan 同時註冊了一般連結（`VIEW`）與 NFC 標籤（NDEF）兩種接收方式，`maiscan://` 與 `maiscan://info/…` 兩種形式都能被接收。

## 10. 完整範例

查看曲目詳細頁：

```
maiscan://info/songID=10721
```

隨機查看一首：

```
maiscan://info/songID=random
```

靜默匯入（目標應用程式未執行時最省心）：

```
maiscan://info/songID=10721{plugin="com.exp.pack",action=run,execution=1}
```

目標應用程式執行中（`sweep=1` 會在崩潰後再次拉起）：

```
maiscan://info/songID=10721{plugin="com.exp.pack",action=run,execution=1,sweep=1}
```

排查問題（逐步提示）：

```
maiscan://info/songID=10721{plugin="com.exp.pack",action=run,execution=1,sweep=1,debug=1}
```

送入內建播放器：

```
maiscan://info/songID=10721{action=play}
```

隨機選曲並播放：

```
maiscan://info/songID=random{action=play}
```

百分比編碼寫法（與上方靜默匯入等價）：

```
maiscan://info/songID=10721%7Bplugin=%22com.exp.pack%22,action=run,execution=1%7D
```

## 11. 相容性與限制

- **平台**：Android 6.0 以上；但 **`run` / `play` 依賴新版介面與外掛系統**，需要 Android 8.0 以上且為 64 位元裝置。
- **舊裝置限制**：Android 8.0 以下或 32 位元裝置只能使用 Legacy 介面，**沒有外掛功能** —— 這類裝置上帶 `plugin` 的連結不會執行，會以「外掛未安裝 / 未啟用」落到曲目詳細頁。`maiscan://` 與純 `songID` 連結不受影響。
- **離線**：全部在本機處理，不發起網路請求。
- **外掛前提**：`run` 需要外掛宣告目標套件名稱（`metadata.ini` 的 `targetPackage`）；未宣告時只能退化成系統的應用程式選擇器，無法靜默。
- **目標應用程式行為**：若目標應用程式不處理執行中的啟動請求，只能用 `sweep` 嘗試；Unity 類目標在匯入瞬間會崩潰一次，詳見第 7 節。更徹底的做法是目標應用程式在收到新的啟動請求時重新讀取連結內容。
- **語言**：連結語法與系統語言無關；介面文字隨應用程式語言設定變化。

## 12. 常見問題

**Q：整合包的子套件名稱怎麼確定？**

解壓縮整合包，`msrpack/` 下每個 `.msrp` 都是獨立子包；其 `pack_manifest.ini` 中 `package=`（或 `name=`）的值就是子套件名稱，直接寫進 `plugin=` 即可，不需要拼接父包名，也不要加檔名或副檔名。

**Q：子包寫了卻不生效？**

子包依賴父包：父整合包必須已安裝且已啟用，該子包本身也不能被單獨停用。

**Q：`songID=random` 一首都沒選到，為什麼直接進主介面？**

可能是白名單與黑名單過濾後沒有候選，或指定的外掛 / 子包未涵蓋任何曲目。隨機選曲在此情況視為「曲目不存在」，不顯示提示。

**Q：`action=play` 沒有聲音？**

先確認內建播放器已啟用（否則會停留在詳細頁，由頁面內播放）；其次確認該曲在已啟用的外掛裡確實有可播放音訊（`.aiu` / `.adx` / `.mp3` 等）。

**Q：舊手機（Android 8.0 以下 / 32 位元）能用這些連結嗎？**

開啟主介面、開啟曲目詳細頁可以；`action=run` 與 `action=play` 不行 —— 舊裝置只能使用 Legacy 介面，沒有外掛與內建播放器，帶 `plugin` 的連結會以外掛未安裝 / 未啟用處理。

**Q：`action=run` 跳出「選擇應用程式」，沒有靜默執行？**

表示外掛未宣告目標套件名稱。`run` 的靜默能力依賴外掛宣告目標應用程式；未宣告時系統只能讓使用者手動選擇。

**Q：為什麼連結中的目標應用程式沒有反應？**

多數目標應用程式只在冷啟動時讀取匯入內容。目標在背景時 `sweep` 也無法注入；目標在前景時 Unity 類目標會崩潰一次，`sweep=1` 會在崩潰後再次拉起並繼續匯入。詳見第 7 節。

**Q：連結可以帶 `debug=1` 發布給一般使用者嗎？**

可以，但會逐步顯示執行提示。面向一般使用者發布時建議省略該參數。
