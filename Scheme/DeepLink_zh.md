# MaiScan Rev 深链（`maiscan://`）规范

**适用**：MaiScan Rev `build.20261126` 及以后　**平台**：Android 6.0 及以上（`run` / `play` 需新版界面，见第 11 节）

本文档面向希望从其它应用、NFC 标签、二维码或自动化工具唤起 MaiScan Rev 并执行指定动作的开发者与进阶用户。

## 1. 概述

`maiscan://` 用于让外部触发 MaiScan Rev 支持执行以下动作：

- 打开主界面
- 打开指定曲目的详情页
- 将指定曲目的文件交给插件声明的目标应用
- 将指定曲目送入 MaiScan 内置播放器

---

## 2. 链接结构

```
maiscan://info/songID=<曲目 ID 或 random>{参数列表}
```

| 链接 | 行为 |
|---|---|
| `maiscan://` | 打开主界面（裸 scheme 视为合法链接）|
| `maiscan://info/songID=10721` | 打开 10721 的曲目详情页 |
| `maiscan://info/songID=random` | 随机选择一首，打开其详情页 |
| `maiscan://info/songID=10721{plugin="com.exp.pack",action=run,execution=1}` | 静默执行：直接将该曲文件交给插件指定的目标应用 |
| `maiscan://info/songID=10721{action=play}` | 送入内置播放器；未启用播放器时停留在详情页 |

**书写约定**

- 参数列表用 `{` `}` 包裹，参数之间用 `,` 分隔，形如 `key=value`。
- 字符串值建议使用双引号；`songID` 的值可带可不带引号。
- `{` `}` `"` 不是标准 URI 字符。若写入工具进行了百分号编码（`%7B` `%7D` `%22`），MaiScan 会先解码再解析，两种写法均受支持。

---

## 3. 参数说明

| 参数 | 取值 | 含义 |
|---|---|---|
| `plugin` | 插件包名 | 负责执行操作的插件。整合包可写**父包**（自动定位到对应子包），也可直接写**子包包名**：此时只作用于该子包，范围更窄。子包要求父包已启用且该子包未被禁用 |
| `action` | `run` / `play` | 执行动作，见第 4 节 |
| `execution` | `1` / `0` / 省略 | 是否静默执行，见第 5 节。兼容 `true` / `false` |
| `sweep` | `1` / `2` / 省略 | 仅对 `action=run` 生效，见第 7 节 |
| `wlist` | `"1,2,3"` | 仅 `songID=random` 时生效：白名单 |
| `blacklist` | `"1,2,3"` | 仅 `songID=random` 时生效：黑名单 |
| `debug` | `1` / `0` | `1` 时以 Toast 输出执行步骤；省略或 `0` 时不显示任何提示 |

未识别的参数会被忽略，不影响链接有效性。

---

## 4. 动作 `action`

| 值 | 行为 |
|---|---|
| `run` | 模拟详情页中的插件按钮。FILE 类插件：将该曲文件交给插件声明的目标应用；WEB 类插件：用浏览器打开其声明的网址 |
| `play` | 将音频送入 MaiScan 内置播放器。解析成功后回到主界面，由悬浮播放器继续播放；内置播放器未启用时停留在该曲详情页并页内播放 |

**`play` 的音频来源**

1. 优先按曲目 ID 从已启用插件中解析：`.aiu`（配合 `.arup`）、`.adx`、`.mp3`、`.ogg` / `.oga`、`.flac`、`.wav`；
2. 解析不到时，回退到插件按钮声明的可播放文件。

`play` 不要求 `plugin`；其余格式（如 `.m4a`、`.aac`、`.opus`）是否可播取决于设备解码能力，不保证支持。

### WEB 插件

WEB 类插件没有文件和目标包名，只有网址（`Webrule.json` 的 `url`）。对其使用 `action=run` 会直接用浏览器打开该网址，占位符 `[id]`、`[title]`、`[artist]` 照常替换。

- 网址的 scheme 不限：`https://` 与自定义 scheme（如 `astrodx://…`）均由系统分发。
- 防递归：若插件的目标地址仍是 `maiscan://`，该次调用直接判定失败并停在详情页。
- FILE 类插件同理：目标包名指向 MaiScan 自身时会被拒绝。
- WEB 插件不支持 `sweep`，因为它不涉及在目标应用内导入。

## 5. 静默执行 `execution`

| 值 | 行为 |
|---|---|
| `1`（或 `true`）| 尝试静默：执行成功时不显示任何界面 |
| 省略 / `0`（或 `false`）| 先打开详情页，随后由宿主模拟执行对应按钮 |

## 6. 随机选曲 `songID=random`

将 `songID` 写为 `random`（大小写不敏感）即可随机选择一首曲目。

**过滤规则（按顺序应用）**

1. `wlist` 非空时，仅在其中选取；
2. 排除 `blacklist` 中的曲目；
3. 指定了 `plugin` 时，仅保留该插件覆盖的曲目：满足 `[SongList]` / `%file%` 规则；FILE 类还要求确实存在文件（`pack-all` 视为全部覆盖）；整合包允许父包或任一已启用子包命中；若写的是子包包名，则只在该子包范围内选取。

若候选为空，按“曲目不存在”处理，进入主界面且不显示提示。

```
maiscan://info/songID=random
maiscan://info/songID=random{wlist="10721,10722"}
maiscan://info/songID=random{blacklist="9"}
maiscan://info/songID=random{action=play}
```

## 7. 运行中目标 `sweep`

目标应用（例如 AstroDX）只在冷启动时读取导入内容，运行中收到新的启动请求会忽略。`sweep` 用于"目标已经跑着"时尝试导入。

| 值 | 做法 | 实测结果（仅 AstroDX）|
|---|---|---|
| 省略（=0）| 常规启动 | 目标在后台：**无法注入**；把目标重启后再试，同样注入不了。目标在前台：启动会**直接崩溃**，且没有后续拉起，可能直接看到错误弹窗（Unity）|
| `sweep=1` | 与 0 相同，但崩溃后会**再次拉起目标应用** | 同样会出现崩溃弹窗，但大部分一闪而过；若弹窗未被关闭/取消，导入会继续执行 |
| `sweep=2` | 让目标在自己的任务栈中新开一个任务 | 通常不崩溃；代价是每触发一次，最近任务就多一条该应用 |

⚠️ 以上**只实测过 AstroDX**；其他 App 的行为不确定，其他"Unity 且支持外部导入"的 App 理论上同理。

使用 `sweep` 时一律走静默导入流程，`execution` 不再影响是否静默。

两种模式都会在导入后约 1.8 秒尝试将目标应用拉回前台；失败时仅记录日志，`debug=1` 时以 Toast 提示。

## 8. 失败落点

| 情况 | 落点 |
|---|---|
| 链接格式错误 / 无法解析曲目 ID / ID 不在曲库 | 主界面（不提示）|
| ID 有效但未指定 `plugin` 与 `action` | 曲目详情页 |
| 参数不合法（如 `action` 非 `run` / `play`）| 曲目详情页 |
| 插件未安装 / 已安装未启用 | 曲目详情页 |
| 插件中不存在该曲文件 | 曲目详情页 |
| 目标应用未安装或拒绝该文件 | 曲目详情页 |
| `action=play` 解析不到音频 | 曲目详情页 |

> 插件必须“已安装且已启用”才会执行，与详情页按钮的显示规则一致。

## 9. NFC 标签

- 写入一条 **URI 记录**，内容为上文中的 `maiscan://…` 链接。
- 建议同时写入一条 **AAR（Android Application Record）**：`com.MaiScan.Rev`。这样即使设备上存在其它声明了 `maiscan://` 的应用，系统也会将意图直接交给 MaiScan。
- MaiScan 同时注册了普通链接（`VIEW`）与 NFC 标签（NDEF）两种接收方式，`maiscan://` 与 `maiscan://info/…` 两种形态都能被接收。

## 10. 完整示例

查看曲目详情：

```
maiscan://info/songID=10721
```

随机查看一首：

```
maiscan://info/songID=random
```

静默导入（目标应用未运行时最省心）：

```
maiscan://info/songID=10721{plugin="com.exp.pack",action=run,execution=1}
```

目标应用正在运行（`sweep=1` 会在崩溃后再次拉起）：

```
maiscan://info/songID=10721{plugin="com.exp.pack",action=run,execution=1,sweep=1}
```

排查问题（逐步提示）：

```
maiscan://info/songID=10721{plugin="com.exp.pack",action=run,execution=1,sweep=1,debug=1}
```

送入内置播放器：

```
maiscan://info/songID=10721{action=play}
```

随机选曲并播放：

```
maiscan://info/songID=random{action=play}
```

百分号编码写法（与上面的静默导入等价）：

```
maiscan://info/songID=10721%7Bplugin=%22com.exp.pack%22,action=run,execution=1%7D
```

## 11. 兼容性与限制

- **平台**：Android 6.0 及以上；但 **`run` / `play` 依赖新版界面与插件系统**，要求 Android 8.0 及以上且为 64 位设备。
- **旧设备限制**：Android 8.0 以下或 32 位设备只能使用 Legacy 界面，**没有插件功能** —— 这类设备上带 `plugin` 的链接不会执行，会按“插件未安装/未启用”落到曲目详情页。`maiscan://` 与纯 `songID` 链接不受影响。
- **离线**：全部处理在本地完成，不发起网络请求。
- **插件前提**：`run` 要求插件声明目标包名（`metadata.ini` 中的 `targetPackage`）；未声明时只能退化为系统应用选择器，无法做到静默。
- **目标应用行为**：若目标应用不处理运行中的启动请求，只能用 `sweep` 尝试；Unity 类目标在导入瞬间会崩溃一次，详见第 7 节。更彻底的做法是目标应用在收到新的启动请求时重新读取链接内容。
- **语言**：链接语法与系统语言无关；界面文案随应用语言设置变化。

## 12. 常见问题

**Q：整合包的子包包名怎么确定？**

解压整合包，`msrpack/` 下每个 `.msrp` 都是独立子包；其 `pack_manifest.ini` 中 `package=`（或 `name=`）的值就是子包包名，直接写进 `plugin=` 即可，不需要拼接父包名，也不要加文件名或扩展名。

**Q：子包写了却不生效？**

子包依赖父包：父整合包必须已安装且已启用，该子包本身也不能被单独禁用。

**Q：`songID=random` 一个都没选到，为什么直接进主界面？**

可能是白名单与黑名单过滤后没有候选，或指定的插件/子包未覆盖任何曲目。随机选曲在这一情况下按“曲目不存在”处理，不弹提示。

**Q：`action=play` 没有声音？**

先确认内置播放器已启用（否则会停留在详情页，由页面内播放）；其次确认该曲在已启用的插件里确实有可播放音频（`.aiu` / `.adx` / `.mp3` 等）。

**Q：旧手机（Android 8.0 以下 / 32 位）能用这些链接吗？**

打开主界面、打开曲目详情可以；`action=run` 与 `action=play` 不行 —— 旧设备只能使用 Legacy 界面，没有插件与内置播放器，带 `plugin` 的链接会按“插件未安装/未启用”处理。

**Q：`action=run` 弹出了“选择应用”，没有静默执行？**

说明插件未声明目标包名。`run` 的静默能力依赖插件声明目标应用；未声明时系统只能让用户手动选择。

**Q：为什么链接里的目标应用没有响应？**

多数目标应用只在冷启动时读取导入内容。目标在后台时 `sweep` 也无法注入；目标在前台时 Unity 类目标会崩溃一次，`sweep=1` 会在崩溃后再次拉起并继续导入。详见第 7 节。

**Q：链接可以带 `debug=1` 发布给普通用户吗？**

可以，但会逐步弹出执行提示。面向普通用户发布时建议省略该参数。
