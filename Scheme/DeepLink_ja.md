# MaiScan Rev ディープリンク（`maiscan://`）仕様

**バージョン**：1.0　**対象**：MaiScan Rev `build.20261126` 以降　**プラットフォーム**：Android 6.0 以降（`run` / `play` は新しい UI が必要。第 11 章参照）

本書は、他のアプリ・NFC タグ・QR コード・自動化ツールから MaiScan Rev を起動し、特定の動作を行わせたい開発者・上級ユーザー向けです。

## 1. 概要

`maiscan://` を使うと、外部から MaiScan Rev に次の動作を行わせられます。

- メイン画面を開く
- 指定した楽曲の詳細ページを開く
- 指定した楽曲のファイルを、プラグインが指定する対象アプリへ渡す
- 指定した楽曲を MaiScan 内蔵プレイヤーへ送る

---

## 2. リンク構造

```
maiscan://info/songID=<楽曲 ID または random>{パラメータ一覧}
```

| リンク | 動作 |
|---|---|
| `maiscan://` | メイン画面を開く（裸の scheme も有効なリンクとして扱う）|
| `maiscan://info/songID=10721` | 10721 の楽曲詳細ページを開く |
| `maiscan://info/songID=random` | ランダムに 1 曲選び、その詳細ページを開く |
| `maiscan://info/songID=10721{plugin="com.exp.pack",action=run,execution=1}` | サイレント実行：その曲のファイルを対象アプリへ直接渡す |
| `maiscan://info/songID=10721{action=play}` | 内蔵プレイヤーへ送る。プレイヤー未使用時は詳細ページに留まる |

**記述ルール**

- パラメータ一覧は `{` `}` で囲み、`,` で区切り、`key=value` の形で書きます。
- 文字列値はダブルクォートを推奨します。`songID` の値はクォートあり・なしどちらでも構いません。
- `{` `}` `"` は標準的な URI 文字ではありません。書き込みツールがパーセントエンコード（`%7B` `%7D` `%22`）した場合も、MaiScan はデコードしてから解析するため、どちらの書き方も受け付けます。

---

## 3. パラメータ

| パラメータ | 値 | 意味 |
|---|---|---|
| `plugin` | プラグインのパッケージ名 | 動作を担当するプラグイン。バンドルは**親**を書けば対応する子を自動で探します。**子パッケージ名**を直接書くこともでき、その場合はその子だけが対象になります。子を指定する場合、親が有効で子が無効化されていない必要があります |
| `action` | `run` / `play` | 実行する動作。第 4 章参照 |
| `execution` | `1` / `0` / 省略 | サイレント実行かどうか。第 5 章参照。`true` / `false` も可 |
| `sweep` | `1` / `2` / 省略 | `action=run` のときのみ有効。第 7 章参照 |
| `wlist` | `"1,2,3"` | `songID=random` のときのみ有効：ホワイトリスト |
| `blacklist` | `"1,2,3"` | `songID=random` のときのみ有効：ブラックリスト |
| `debug` | `1` / `0` | `1` のとき実行手順を Toast で表示。省略または `0` では何も表示しない |

未知のパラメータは無視され、リンクの有効性には影響しません。

---

## 4. 動作 `action`

| 値 | 動作 |
|---|---|
| `run` | 詳細ページのプラグインボタンを模擬実行します。FILE 系：その曲のファイルを対象アプリへ渡す。WEB 系：宣言された URL をブラウザで開く |
| `play` | 音声を内蔵プレイヤーへ送ります。成功するとメイン画面に戻り、フローティングプレイヤーで再生が続きます。内蔵プレイヤー未使用時は詳細ページに留まり、その場で再生します |

**`play` の音声ソース**

1. まず曲 ID から有効なプラグインを検索：`.aiu`（`.arup` と併用）、`.adx`、`.mp3`、`.ogg` / `.oga`、`.flac`、`.wav`；
2. 見つからない場合は、プラグインボタンが宣言した再生可能ファイルへフォールバックします。

`play` に `plugin` は不要です。その他の形式（`.m4a`、`.aac`、`.opus` など）は端末のデコーダ次第で、対応を保証しません。

### WEB プラグイン

WEB プラグインはファイルも対象パッケージも持たず、URL だけを持ちます（`Webrule.json` の `url`）。`action=run` を指定するとその URL をブラウザで直接開きます。プレースホルダ `[id]`、`[title]`、`[artist]` は通常どおり置換されます。

- URL の scheme は問いません：`https://` も独自 scheme（`astrodx://…` など）もシステムが振り分けます。
- 再帰防止：プラグインの対象が `maiscan://` 自身だった場合、その呼び出しは失敗し、詳細ページに留まります。
- FILE 系も同様で、対象パッケージが MaiScan 自身を指す場合は拒否されます。
- WEB プラグインは対象アプリへのインポートを伴わないため、`sweep` は使用しません。

---

## 5. サイレント実行 `execution`

| 値 | 動作 |
|---|---|
| `1`（または `true`）| サイレントを試みる：成功時は画面を表示しない |
| 省略 / `0`（または `false`）| 先に詳細ページを開き、その後で対応するボタンを模擬実行する |

## 6. ランダム選曲 `songID=random`

`songID` を `random`（大文字小文字は区別しない）と書くと、ランダムに 1 曲選びます。

**絞り込みルール（順に適用）**

1. `wlist` が空でなければ、その中からのみ選ぶ；
2. `blacklist` の曲を除外する；
3. `plugin` が指定されていれば、そのプラグインが対象とする曲だけを残す：`[SongList]` / `%file%` の条件を満たすこと。FILE 系は実際にファイルがあることも必要（`pack-all` は全曲対象とみなす）。バンドルは親または有効な子のいずれかが一致すれば可。子パッケージ名を書いた場合は、その子の範囲だけが対象になります。

候補が空の場合は「曲が存在しない」扱いとなり、メイン画面へ移動して何も表示しません。

```
maiscan://info/songID=random
maiscan://info/songID=random{wlist="10721,10722"}
maiscan://info/songID=random{blacklist="9"}
maiscan://info/songID=random{action=play}
```

## 7. 起動中の対象 `sweep`

対象アプリ（AstroDX など）はコールドスタート時のみインポート内容を読み込み、起動中に新しい起動要求を受けても無視します。`sweep` は「対象がすでに起動している」状態でインポートを試みるためのものです。

| 値 | 方法 | 実測結果（AstroDX のみ）|
|---|---|---|
| 省略（=0）| 通常起動 | 対象がバックグラウンド：**注入できない**。対象を再起動してから試しても同様。対象がフォアグラウンド：起動時に**即クラッシュ**し、その後の再起動もなく、エラーダイアログ（Unity）がそのまま見えることがある |
| `sweep=1` | 0 と同じだが、クラッシュ後に**対象アプリを再度起動する** | クラッシュのダイアログは出るが、ほとんどは一瞬で消える。閉じずにキャンセルしなければインポートは継続する |
| `sweep=2` | 対象が自分のタスクスタックに新しいタスクを作る | 通常はクラッシュしない。代わりに実行するたび最近のタスクが 1 つ増える |

⚠️ 実測は **AstroDX のみ**です。他のアプリの挙動は不明で、外部インポートに対応した他の Unity アプリも理論上は同様と考えられます。

`sweep` 使用時は常にサイレントインポートとなり、`execution` はサイレント可否に影響しません。

どちらのモードも、インポート後約 1.8 秒で対象アプリを前面へ戻そうとします。失敗時はログのみで、`debug=1` のとき Toast を表示します。

## 8. 失敗時の挙動

| 状況 | 移動先 |
|---|---|
| リンク形式が不正 / 曲 ID を解析できない / ID が曲庫にない | メイン画面（表示なし）|
| ID は有効だが `plugin` も `action` もない | 楽曲詳細ページ |
| パラメータが不正（`action` が `run` / `play` 以外など）| 楽曲詳細ページ |
| プラグイン未インストール / インストール済みだが無効 | 楽曲詳細ページ |
| プラグインにその曲のファイルがない | 楽曲詳細ページ |
| 対象アプリ未インストール、またはファイルを拒否 | 楽曲詳細ページ |
| `action=play` で音声を解決できない | 楽曲詳細ページ |

> プラグインは「インストール済みかつ有効」でないと実行されません。詳細ページのボタン表示ルールと同じです。

## 9. NFC タグ

- **URI レコード**を 1 つ書き込み、内容を本書の `maiscan://…` リンクにします。
- 併せて **AAR（Android Application Record）**：`com.MaiScan.Rev` を書き込むことを推奨します。端末上に `maiscan://` を宣言する他のアプリがあっても、システムは MaiScan へ直接渡します。
- MaiScan は通常リンク（`VIEW`）と NFC タグ（NDEF）の両方を受け付けるため、`maiscan://` と `maiscan://info/…` のどちらの形でも受け取れます。

## 10. 完全な例

楽曲詳細を開く：

```
maiscan://info/songID=10721
```

ランダムに 1 曲開く：

```
maiscan://info/songID=random
```

サイレントインポート（対象アプリが起動していないとき最も簡単）：

```
maiscan://info/songID=10721{plugin="com.exp.pack",action=run,execution=1}
```

対象アプリが起動中（`sweep=1` はクラッシュ後に再起動します）：

```
maiscan://info/songID=10721{plugin="com.exp.pack",action=run,execution=1,sweep=1}
```

問題調査（手順を順に表示）：

```
maiscan://info/songID=10721{plugin="com.exp.pack",action=run,execution=1,sweep=1,debug=1}
```

内蔵プレイヤーへ送る：

```
maiscan://info/songID=10721{action=play}
```

ランダムに選んで再生：

```
maiscan://info/songID=random{action=play}
```

パーセントエンコード表記（上のサイレントインポートと等価）：

```
maiscan://info/songID=10721%7Bplugin=%22com.exp.pack%22,action=run,execution=1%7D
```

## 11. 互換性と制限

- **プラットフォーム**：Android 6.0 以降。ただし **`run` / `play` は新しい UI とプラグイン機構に依存**するため、Android 8.0 以降かつ 64 ビット端末が必要です。
- **旧端末の制限**：Android 8.0 未満、または 32 ビット端末では Legacy 画面のみ利用でき、**プラグイン機能はありません**。`plugin` を含むリンクは実行されず、「プラグイン未インストール / 無効」として楽曲詳細ページに移動します。`maiscan://` と `songID` のみのリンクは影響を受けません。
- **オフライン**：すべて端末内で処理され、ネットワーク通信は行いません。
- **プラグインの前提**：`run` はプラグインが対象パッケージ名（`metadata.ini` の `targetPackage`）を宣言している必要があります。未宣言の場合、システムのアプリ選択にしかならず、サイレント実行はできません。
- **対象アプリの挙動**：対象アプリが起動中の起動要求を処理しない場合、`sweep` でしか試せません。Unity 系はインポート時に一度クラッシュします（第 7 章）。より根本的な解決は、対象アプリが新しい起動要求を受けたときにリンク内容を読み直すことです。
- **言語**：リンク構文はシステム言語に依存しません。画面の文言はアプリの言語設定に従います。

## 12. よくある質問

**Q：バンドルの子パッケージ名はどう調べますか？**

バンドルを解凍すると、`msrpack/` 内の各 `.msrp` が独立した子です。その `pack_manifest.ini` の `package=`（または `name=`）の値が子パッケージ名です。`plugin=` にそのまま書き、親名を前置したり、ファイル名や拡張子を付けたりしないでください。

**Q：子パッケージを書いたのに動きません。**

子は親に依存します。親バンドルがインストール済みかつ有効で、その子が個別に無効化されていない必要があります。

**Q：`songID=random` が 1 曲も選ばれず、メイン画面に戻りました。**

ホワイトリスト / ブラックリストで候補が空になったか、指定したプラグイン / 子がどの曲も対象にしていない可能性があります。この場合のランダム選曲は「曲が存在しない」扱いで、通知は表示しません。

**Q：`action=play` で音が出ません。**

まず内蔵プレイヤーが有効か確認してください（無効だと詳細ページに留まり、その場で再生します）。次に、有効なプラグインにその曲の再生可能な音声（`.aiu` / `.adx` / `.mp3` など）があるか確認してください。

**Q：旧端末（Android 8.0 未満 / 32 ビット）でもこれらのリンクは使えますか？**

メイン画面や楽曲詳細を開くことはできますが、`action=run` と `action=play` は使えません。旧端末は Legacy 画面のみでプラグインも内蔵プレイヤーもないため、`plugin` を含むリンクは「プラグイン未インストール / 無効」として扱われます。

**Q：`action=run` で「アプリを選択」が出て、サイレント実行になりません。**

プラグインが対象パッケージ名を宣言していないためです。サイレントな `run` は対象アプリの宣言に依存するため、未宣言だとシステムはユーザーに選ばせるしかありません。

**Q：リンク先の対象アプリが反応しません。**

多くの対象アプリはコールドスタート時のみインポート内容を読みます。対象がバックグラウンドの場合 `sweep` でも注入できません。フォアグラウンドの場合、Unity 系は一度クラッシュし、`sweep=1` がクラッシュ後に再起動してインポートを継続します（第 7 章）。

**Q：`debug=1` 付きリンクを一般ユーザーへ配布してもよいですか？**

可能ですが、実行手順が順に表示されます。一般向けにはこのパラメータを外すことを推奨します。
